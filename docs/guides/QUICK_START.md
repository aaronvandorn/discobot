# Quick Start

1. `npm install` then `npm run dev`, and open http://localhost:3000 (or open the deployed GitHub Pages site).
2. Click once anywhere so the browser allows audio; make sure the speaker icon in the header isn't muted.
3. Synth: click a step in the sequencer (amber), then click a piano key to assign a note. Or switch to the piano roll and paint notes.
4. Drums: pick an instrument, click cells in the 16-step grid, choose a kit.
5. Press **Play All**. Click the BPM display to change tempo.
6. **+ Save** stores the full pattern in this browser; **Load** recalls it.
7. **Export MIDI** or **Download WAV** to take the loop into another app.
